01 / THINK → ACT → CHECK

Position plus heading is a pose

Use x for east/west and y for north/south. A position says where you are. A heading says where you face. In this course, east is 0°, north 90°, west 180°, and south 270°.

double xCm = 40.0;
double yCm = 40.0;
double headingDeg = 0.0;

02 / THINK → ACT → CHECK

Find the gap

Subtract the current position from the target position. The two differences form a right triangle. Math.hypot gives its straight-line length. Math.atan2 takes y first, then x, and returns radians.

double dx = 140.0 - 40.0;
double dy = 120.0 - 40.0;
double distanceCm = Math.hypot(dx, dy);
double targetDeg = Math.toDegrees(Math.atan2(dy, dx));

03 / THINK → ACT → CHECK

Move along a heading

Convert degrees to radians before using sin or cos. A turn in place changes heading without changing position. A drive changes x and y according to heading. Real wheels can also make curved turns; the motor lab explores that.

double radians = Math.toRadians(headingDeg);
xCm += 20.0 * Math.cos(radians);
yCm += 20.0 * Math.sin(radians);
