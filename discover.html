02 / AUTOMATION AT WORK

Robots help make things.

A contest has a mission. A factory has a job: move a part, join materials, check a result, repeat. Look at these real industrial robots and imagine the instructions behind their movements.

One loop, many jobs.

Sense: Is the part present? Think: Is it in the right place? Act: Move the tool. Check: Did the job succeed? Correct: Adjust or ask for help.

Other examples to investigate: packaging robots stacking boxes, conveyor sensors counting parts, and cameras checking finished products.

03 / BIG IDEAS YOU CAN UNDERSTAND

Could a robot learn a new trick?

You don’t need to understand every equation to ask a great research question. Start with the demonstrations, then follow one idea. These Google DeepMind projects are research demonstrations, not beginner Java tutorials.

ROBOCAT · 2023

One learner. Different robot arms.

RoboCat learns tasks across different robotic arms using demonstrations and practice data. Watch it handle objects and tackle a shape puzzle.

The idea: Examples of what the robot sees and does can help a trained model choose its next action. More varied practice can help it adapt to new tasks; it still makes mistakes.

Wonder: If the gripper changes, which parts of picking up a block stay the same?

Try: Write five steps for placing a block in a box. Move the box. Which measurements must change? Connect this to sensors and geometry.

Watch the official demo ↗

Read Google DeepMind’s illustrated explanation and research paper

LEARNING TO MOVE · 2022

A robot can borrow a movement idea.

Researchers used recorded human and dog movements to help train movement skills in simulation, then used learned skills on real robots. The research includes walking and dribbling a ball; the illustrated article also shows simulated football teams.

The idea: Learn useful small skills, then reuse them in bigger tasks. Reinforcement learning improves choices through trials and feedback from a goal.

Wonder: Is chasing the ball always the best way for a team to score?

Try: Sketch a robot, a ball, and a goal. Plan where the robot should stand before pushing the ball. Try that approach route in the Geometry Bench.

Explore the illustrated research explanation and football video

Want to go one step deeper?

DeepMind’s 2024 research on real, miniature soccer robots trained walking, turning, kicking, and getting up in simulation before transferring to physical robots. Compare the abstract with the earlier simulated teams: what extra problems appear when a robot has a real body?

You can start here: observe one action, make a prediction, test a small version, and explain what changed. The advanced math can come later.

05 / A QUICK PYTHON REFERENCE

Same ideas. Another language.

Java is our course language. Python is another way to express variables, decisions, and repeated actions. Here’s a small translation guide; you don’t need to learn both at once.

Java

int distanceCm = 20;
boolean pathClear = true;

if (pathClear) {
    System.out.println("Move " + distanceCm);
} else {
    System.out.println("Stop");
}

for (int step = 0; step < 3; step++) {
    System.out.println(step);
}

Python

distance_cm = 20
path_clear = True

if path_clear:
    print("Move", distance_cm)
else:
    print("Stop")

for step in range(3):
    print(step)

Try a tiny prediction

Change path_clear to False. The Python example prints Stop, then prints 0, 1, and 2. The loop is outside the decision, so it still runs.

These examples print messages; they don’t control hardware. The Java fragment belongs inside a method. Python robot commands depend on the library and hardware you choose. This page does not execute either language.
