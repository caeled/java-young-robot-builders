THE COURSE MAP

From first command
to clever machine.

One small experiment at a time. Each mission follows our loop: Sense → Think → Act → Check → Correct.

Available now: Module 1 and the Geometry Bench prototype. Modules 2–9 below are planned, not finished lessons.

01
READY TO BUILD

Meet the Robot Brain

Commands, sequence, variables, methods, and a first decision. Explain your plan before you run it.

“I can tell a robot to do something in steps.”

Begin the first mission →
02
PLANNED

Java for Robot Builders

Numbers, booleans, if/else, loops, and methods. Build a robot traffic-light game and repeat a simple patrol.

“I can write logic that changes what a robot does.”

03
PLANNED

Sensors Are Robot Senses

Touch, distance, color/light, encoders, and gyro/IMU. Compare measurements with reality and experiment with noise, delay, and calibration.

“A sensor gives me a measurement. I need to check what it means.”

04
PLANNED

Position & Geometry

x/y coordinates, degrees, headings, distance, triangles, and turning radius. Predict a route, then measure the result.

“I can describe where I am and where I want to go.”

Try the early Geometry Bench →
05
PLANNED

Motors & Movement

Power versus speed, direction, wheel size, and gear ratios. Explore why equal motor power doesn’t always mean straight travel.

“I can test how motor commands change movement.”

06
PLANNED

Automation in Action

Inputs → decision → action. Use timers, sequences, and simple state machines to wait, detect, move, and check.

“I can make a robot respond without a new instruction each time.”

07
PLANNED

Debug Like a Builder

Expected versus actual behavior, logs, test cases, and changing one thing at a time. Find clues in a deliberately broken mission.

“I can use evidence to improve my program.”

08
PLANNED

Check & Correct

Combine position estimates and sensor readings. Try small corrections, stop tolerances, and limits that keep an automated routine from running forever.

“I can compare my goal with a measurement and choose a correction.”

09
PLANNED

Your Autonomous Mission

Design a delivery challenge. Plan a route, choose sensors, write a routine, record test results, and explain your improvements.

“I can build, test, and explain a robot mission of my own.”

A note for mentors

Use this as an optional learning track. Let students explain predictions and choose experiments. Start in the browser; introduce a real robot later with its own hardware documentation and supervision.

The Java examples use a teaching API, not a particular robot SDK. Browser benches simulate the ideas with JavaScript; they do not compile or execute Java.
