# Research and Java discovery resources

Selections checked October 5, 2026. The explanations and activity prompts on Discover are original course text. External media, code, and artwork remain under their owners’ terms and are not covered by this course’s licenses.

- [Google DeepMind: RoboCat (2023)](https://deepmind.google/blog/robocat-a-self-improving-robotic-agent/). Official demo video: `535W4Pih1C0`, as embedded on the article.
- [Google DeepMind: From motor control to embodied intelligence (2022)](https://deepmind.google/blog/from-motor-control-to-embodied-intelligence/). Official Imitate and Repurpose summary: `K77HS6uO5F8`, linked by the article. Distinguish simulated football teams from real robots using learned movement skills.
- [Google DeepMind: Learning Agile Soccer Skills for a Bipedal Robot (2024)](https://deepmind.google/research/publications/31284/). Optional deeper reading about simulation training transferred to miniature real robots.
- [Greenfoot Ants by mik](https://www.greenfoot.org/scenarios/1016). HTML5 demo visually checked in the browser. The [book scenario guide](https://www.greenfoot.org/book/scenario-list.html) describes ants searching for food using pheromone trails.
- [Greenfoot microkong by lordhershey](https://www.greenfoot.org/scenarios/10340). HTML5 demo visually checked in the browser; creator’s instructions specify arrow keys and Space. Project page offers source download. No project code or artwork is copied into this repository.

Direct Greenfoot demo links use the site’s documented `?embed=true` view to show the canvas without community comments. HTML5 versions run in the browser; editing the original Java projects requires desktop Greenfoot. Research and game demonstrations are optional resources, not prerequisites.
