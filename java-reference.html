Basics

A complete Java program

A class groups code. The familiar main method is where these desktop examples start. Save a public class in a file with the same name.

public class HelloRobot {
    public static void main(String[] args) {
        System.out.println("Hello, builder!");
    }
}

Watch for: HelloRobot belongs in HelloRobot.java. Java is case-sensitive.

Variables & unit names

Store information in a named value. A unit in the name helps distinguish centimeters, degrees, and seconds.

int laps = 3;
double distanceCm = 20.5;
boolean pathClear = true;

Watch for: Initialize a local variable before reading it. distanceCm and DistanceCm are different names.

Basics

Types: int, long, double, boolean, String

Choose a type for the job: int for small whole counts, long for large counts or time differences, double for decimal measurements, boolean for a yes/no result, and String for text.

int ticks = 360;
long elapsedNanos = 1_000_000_000L;
double power = 0.5;
boolean enabled = false;
String label = "left wheel";

Watch for: double is approximate. It is useful for measured quantities; test against a tolerance.

Basics

Constants with final

Name a value that your routine should not reassign. A fixed threshold is easier to review when it has a meaningful name.

final double STOP_DISTANCE_CM = 20.0;
final int MAX_STEPS = 30;

Watch for: final prevents reassignment. It does not make every object it refers to immutable.

Basics

Arithmetic & integer division

Use +, −, *, /, and % to calculate. Parentheses make intended grouping clear. Integer division discards the fractional part.

int whole = 5 / 2; // 2
double ratio = 5.0 / 2; // 2.5
int remainder = 5 % 2; // 1

Watch for: Assigning 5 / 2 to a double still starts with integer division. Use a decimal operand.

Basics

Conversions & casts

Java can widen int to double automatically. A cast to int truncates a decimal toward zero. Choose rounding explicitly when you want the nearest whole count.

double measuredCm = 19.8;
int truncated = (int) measuredCm; // 19
long rounded = Math.round(measuredCm); // 20

Watch for: A cast does not validate the input or preserve every bit. Check range and meaning first.

Basics

Strings & equality

Text is a String object. equals compares text content; == compares object references when used on objects.

String stateName = "WAIT";
boolean waiting = "WAIT".equals(stateName);
System.out.println("State: " + stateName);

Watch for: Do not use == to compare text. Calling equals on a possibly null variable can fail; a literal first avoids that.

Comments & readable code

Use a short comment for a reason or assumption. Names and small blocks should explain the ordinary steps.

// Teaching field uses centimeters.
double xCm = 40.0;
/* Heading 0 degrees points east. */

Watch for: A comment does not change what a program does. Keep it accurate when code changes.

Basics

Scope: where a name exists

A local variable declared inside a block is available within that block. Method parameters exist inside their method.

for (int lap = 0; lap < 3; lap++) {
    System.out.println(lap);
}
// lap is not available here.

Watch for: An inner declaration can hide a field of the same name. Use clear names and this.field when needed.

Control flow

if / else & comparisons

Choose behavior using a boolean expression. Test == for numeric equality, != for difference, and <, <=, >, >= for ordering.

double distanceCm = 20.0;
if (distanceCm > 20.0) {
    System.out.println("CLEAR");
} else {
    System.out.println("WAIT");
}

Watch for: = assigns; == compares. Include the exact boundary in your tests.

Control flow

Combine decisions with &&, ||, !

&& requires both conditions. || accepts either. ! reverses a boolean. Short-circuit operators can avoid evaluating a second expression when it is unnecessary.

boolean enabled = true;
double distanceCm = 35.0;
boolean canMove = enabled && distanceCm > 20.0;
boolean mustWait = !canMove;

Watch for: Parenthesize mixed conditions when it clarifies the rule. A sensor interpretation still needs evidence.

Control flow

Counted for loops

A counted loop has a start, a condition checked before each pass, and an update after each pass.

for (int step = 0; step < 3; step++) {
    System.out.println(step);
}

Watch for: < 3 visits 0, 1, 2. <= 3 also visits 3. Trace the values to find off-by-one bugs.

Use it in Module 2 · Link to this entry · Official Java documentation ↗

Control flow

Bounded while loops

A while loop repeats while its condition is true. An experiment needs a stopping condition and a limit even when a measurement never changes.

int attempts = 0;
while (attempts < 3) {
    System.out.println("Check " + attempts);
    attempts++;
}

Watch for: A loop that never updates the tested value can run forever. Hardware control updates should remain responsive.

Control flow

break & continue

break leaves the nearest loop; continue skips the rest of the current loop pass. Use them sparingly so the route through the code stays clear.

for (int step = 0; step < 5; step++) {
    if (step == 3) break;
    if (step == 1) continue;
    System.out.println(step); // 0, then 2
}

Watch for: continue can accidentally skip an important update in a while loop.

Control flow

enum & switch for states

An enum names a fixed set of states. A switch makes each state’s response visible in one place. The classic statement syntax here works in Java 17 and later.

enum State { WAIT, DRIVE, DONE }
// Inside a method:
State state = State.WAIT;
switch (state) {
    case WAIT: System.out.println("Waiting"); break;
    case DRIVE: System.out.println("Moving"); break;
    case DONE: System.out.println("Stopped"); break;
}

Watch for: Without break, a classic switch can fall through. State transitions and motor outputs must agree.

Objects & methods

Methods, parameters & return values

A method names a repeatable calculation or action. Its signature declares parameter types and its return type. void means it returns no value.

static boolean isClear(double cm) {
    return cm > 20.0;
}
// Inside main:
boolean clear = isClear(35.0);

Watch for: This snippet has a method declaration: place it in the class outside main.

Objects & methods

Classes, objects & constructors

A class describes a kind of object. A constructor creates its initial state. new makes an instance, and a dot accesses its visible members.

static class Pose {
    double xCm;
    Pose(double startX) { xCm = startX; }
}
// Inside main:
Pose robotPose = new Pose(40.0);

Watch for: The nested class goes inside the outer class, outside main. Each new Pose has its own xCm.

Objects & methods

public, private & this

private limits a member to its class. public exposes it to other code. this refers to the current instance, useful when a parameter and field share a name.

static class Wheel {
    private double diameterCm;
    Wheel(double diameterCm) {
        this.diameterCm = diameterCm;
    }
    public double circumferenceCm() {
        return Math.PI * diameterCm;
    }
}

Watch for: Keep a value private when changing it needs validation. A visible setter should check its input.

Objects & methods

static versus instance members

A static member belongs to the class; an instance member belongs to one object. Math.hypot is static. A robot object’s position should usually belong to that particular robot.

static double distance(double dx, double dy) {
    return Math.hypot(dx, dy);
}

Watch for: main is static, so it cannot directly use an instance field without an object.

Objects & methods

Interfaces: a shared promise

An interface declares behavior another class can implement. It can separate a simulated sensor from a real sensor behind the same small contract.

interface DistanceSource {
    double readCm();
}
static class FakeDistance implements DistanceSource {
    public double readCm() { return 40.0; }
}

Watch for: These declarations go in the outer class, outside main. A real implementation must document invalid readings.

Data & collections

Arrays & indexing

An array holds a fixed number of values. The first index is 0; the final valid index is length − 1.

double[] readings = {39.0, 40.0, 41.0};
System.out.println(readings[0]);
for (int i = 0; i < readings.length; i++) {
    System.out.println(readings[i]);
}

Watch for: readings[readings.length] is outside the array. Check an index before using it.

Data & collections

Enhanced for loop

Visit each item without managing an index. This is useful for calculating with a batch of readings.

double[] readings = {39, 40, 41};
double sum = 0;
for (double cm : readings) {
    sum += cm;
}
double averageCm = sum / readings.length;

Watch for: Check that the batch is non-empty before dividing by its length.

Data & collections

List & ArrayList

A list grows as you add entries. Use a typed List so the compiler can help you keep its items consistent.

// Imports at the top of the file:
import java.util.List;
import java.util.ArrayList;
// Inside main:
List<String> log = new ArrayList<>();
log.add("WAIT");
System.out.println(log.get(0));

Watch for: get uses zero-based indexes. Keep a limit on logs in a long-running robot program.

Data & collections

Map & named settings

A map associates a key with a value. A default value helps when an optional setting is absent.

// Imports at the top:
import java.util.Map;
import java.util.HashMap;
// Inside main:
Map<String, Double> settings = new HashMap<>();
settings.put("stopCm", 20.0);
double stopCm = settings.getOrDefault("stopCm", 15.0);

Watch for: A default is a design choice, not proof that a required setting is present. Validate required configuration.

Data & collections

null & missing information

null means an object reference does not refer to an object. It is different from a measured zero. Check a reference before calling a method on it.

String readingText = null;
if (readingText == null) {
    System.out.println("No reading text");
}

Watch for: Calling a method on null throws NullPointerException. Do not silently turn missing evidence into a clear path.

Robot math

Distance, headings & radians

A robot field uses two coordinate differences. hypot calculates length. atan2(dy, dx) finds direction in radians; convert that to degrees for the course convention.

double dx = 100.0, dy = 80.0;
double cm = Math.hypot(dx, dy);
double headingDeg = Math.toDegrees(Math.atan2(dy, dx));

Watch for: atan2 takes y first. At zero distance, stop instead of asking for a direction.

Use it in Module 4 · Link to this entry · Official Java documentation ↗

Robot math

sin, cos & coordinate movement

A distance along a heading changes x by distance × cos and y by distance × sin. Java’s trigonometric functions take radians.

double xCm = 40, yCm = 40;
double headingDeg = 90;
double radians = Math.toRadians(headingDeg);
xCm += 20 * Math.cos(radians);
yCm += 20 * Math.sin(radians);

Watch for: A tiny residual near zero is normal floating-point behavior. Display rounding does not change the calculation.

Robot math

Normalize an angle & shortest turn

The remainder operator can be negative. Add and repeat the remainder to wrap into 0–360. Normalize both angles before finding a shortest signed turn.

double heading = -90.0;
double normalized = ((heading % 360) + 360) % 360;
double target = 0.0;
double turn = ((target - normalized + 540) % 360) - 180;

Watch for: The shortest-turn expression assumes both headings are normalized first. At 180°, either turn direction is equally short.

Robot math

Error, gain & tolerance

Error compares a goal with a measurement. A gain scales a correction. A tolerance says when the error is acceptable.

double goalCm = 100, measuredCm = 99;
double errorCm = goalCm - measuredCm;
boolean reached = Math.abs(errorCm) <= 2.0;
double correctionCm = 0.5 * errorCm;

Watch for: Do not use exact double equality to decide whether a measured target has been reached.

Robot math

Clamp a motor power or correction

A clamp limits a value to a chosen range. This nested min/max form works without relying on newer Math methods.

double requestedPower = 1.4;
double power = Math.max(-1.0, Math.min(1.0, requestedPower));

Watch for: Check Double.isFinite before clamping external readings. NaN is not made valid by a clamp.

Robot math

Finite readings & calibration

Validate a measurement before interpreting it. Calibration adjusts a known offset, while averaging and filtering address other kinds of variation.

double rawCm = 45.0;
if (Double.isFinite(rawCm) && rawCm >= 0 && rawCm <= 200) {
    double correctedCm = rawCm - 5.0;
    System.out.println(correctedCm);
}

Watch for: The valid range must come from the chosen sensor. Recheck corrected values when calibration can move them out of range.

Robot math

Encoder counts, wheel size & gearing

Convert counts to motor turns, then wheel turns, then centimeters. Use floating-point division and define exactly where the encoder is mounted.

double ticks = 720;
double ticksPerMotorTurn = 360;
double motorTurns = ticks / ticksPerMotorTurn;
double wheelTurns = motorTurns / 3.0;
double travelCm = wheelTurns * Math.PI * 10.0;

Watch for: This example assumes motor-side ticks and a 3:1 reduction. Wheel-side encoders use a different conversion.

Testing & tools

Elapsed time with nanoTime

Compare two nanoTime readings for elapsed duration. The reading is not a wall-clock date or time. Use a long for nanoseconds and convert only the difference.

long start = System.nanoTime();
// Later in the routine:
double elapsedSeconds = (System.nanoTime() - start) / 1_000_000_000.0;

Watch for: Do not compare nanoTime values from different processes. A busy-wait can block a control loop.

Testing & tools

Print useful logs

A log should connect an input to a decision or output. Include units and state so you can compare expected and actual behavior.

double cm = 20.0;
boolean clear = cm > 20.0;
System.out.println("distanceCm=" + cm + ", clear=" + clear);

Watch for: Printing on every fast control update can be noisy or slow. Choose a useful rate and record changes.

Testing & tools

Exceptions & input parsing

A parse failure is different from a valid number. Catch the specific problem and explain it. Catching an exception is not a reason to proceed with unsafe assumptions.

try {
    double cm = Double.parseDouble("not a number");
    System.out.println(cm);
} catch (NumberFormatException error) {
    System.out.println("Please enter a number.");
}

Watch for: Parsing NaN succeeds; still check isFinite. Do not catch every exception and hide a program bug.

Testing & tools

Small tests & boundary cases

A test compares a calculation with an expected answer. Include boundaries and a case that would expose a likely mistake. Throwing AssertionError here fails regardless of assertion flags.

boolean actual = 20.0 > 20.0;
if (actual) {
    throw new AssertionError("20 cm must wait");
}

Watch for: A passing test proves only its tested case. Pair it with 19 and 21 cm, and test invalid readings separately.

Testing & tools

Imports, files & packages

An import lets you use a class name without its full package name. Place imports before the class declaration. java.lang classes such as Math and String need no import.

import java.util.ArrayList;

public class Notebook {
    public static void main(String[] args) {
        ArrayList<String> notes = new ArrayList<>();
        notes.add("Predict first");
    }
}

Watch for: A package organizes classes; it is not a robot configuration. These downloads use no package to keep first runs simple.

Testing & tools

Teaching API versus robot SDK

forward and turnLeft in the course belong to an imaginary teaching robot. Complete example TeachingRobotMission supplies that class as a desktop simulation. A real robot SDK has its own units and update behavior.

// Teaching API fragment:
robot.forward(100);
robot.turnLeft(90);
robot.forward(80);
robot.stop();

Watch for: Copying a fragment does not configure motors, sensors, or emergency stopping. Select and study the actual hardware SDK with a mentor.
