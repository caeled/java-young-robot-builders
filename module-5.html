01 / THINK → ACT → CHECK

Power is a command; speed is a result

A motor power command requests effort. Actual speed depends on load, battery, friction, gearing, and hardware. Our lab deliberately uses a simple ideal relationship so you can study geometry first.

double requestedPower = 0.5;
double idealSpeedCmPerSecond = requestedPower * 50.0;

02 / THINK → ACT → CHECK

Wheel size and gears change travel

One wheel revolution covers circumference = π × diameter, assuming no slip. A 3:1 reduction means three motor revolutions for one wheel revolution. An encoder count must be interpreted with its placement, gearing, and ticks per revolution.

double wheelDiameterCm = 10.0;
double motorTurns = 6.0;
double reduction = 3.0;
double wheelTurns = motorTurns / reduction;
double travelCm = wheelTurns * Math.PI * wheelDiameterCm;

03 / THINK → ACT → CHECK

Two wheels can make a curve

For a differential drive, equal wheel speeds travel straight. Unequal speeds curve. Opposite equal speeds turn in place. Wheel spacing matters: for the same speed difference, wider spacing turns more slowly.

double leftSpeed = 20.0;
double rightSpeed = 30.0;
double trackWidthCm = 20.0;
double forwardSpeed = (leftSpeed + rightSpeed) / 2.0;
double turnRadiansPerSecond = (rightSpeed - leftSpeed) / trackWidthCm;
