Measure, don’t guess

A touch switch reports contact. A distance sensor estimates range. A color/light sensor measures reflected light. An encoder counts rotation. A gyro/IMU measures rotation or motion; it does not magically report perfect field position.

boolean touched = false;
double measuredDistanceCm = 45.0;
int encoderTicks = 360;
double headingDeg = 90.0;

02 / THINK → ACT → CHECK

Bias and noise are different

Bias is a systematic offset: every reading might be about 5 cm too large. Noise changes from reading to reading. Calibration compares readings with a known reference. Averaging can reduce some noise, but does not remove a fixed bias.

double measuredCm = 45.0;
double biasCm = 5.0;
double correctedCm = measuredCm - biasCm;
System.out.println(correctedCm); // 40.0

03 / THINK → ACT → CHECK

Check a reading before using it

A delayed, blocked, out-of-range, or non-finite reading is a clue to stop and investigate. Pick valid ranges from the actual sensor documentation. This example’s 0–200 cm range is only a teaching assumption.

static boolean validDistance(double cm) {
    return Double.isFinite(cm) && cm >= 0 && cm <= 200;
}
// If invalid: do not treat it as a clear path.
